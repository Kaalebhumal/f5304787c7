# The Marketing Semester

A sixteen-week course in marketing — lectures read aloud, figures drawn to be copied by
hand, and a test after each one that tracks which concepts keep going wrong.

Published at **https://kaalebhumal.github.io/f5304787c7/** and asks for a key on first
visit. Deliberately excluded from search engines.

Source and lesson authoring live in a separate private repository; this repository holds
only the built site.
